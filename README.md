# Version V17 avec La salle

La vue « La salle » agrège anonymement : participants, profil dominant, répartition par profil, familles, dimensions moyennes et maturité IA. Chaque navigateur stocke ses résultats localement. Pour regrouper plusieurs appareils sans base partagée, utilisez Exporter puis Importer. Aucun nom, e-mail ou identifiant de personne n’est enregistré.

Remplacez uniquement index.html dans GitHub Pages.
